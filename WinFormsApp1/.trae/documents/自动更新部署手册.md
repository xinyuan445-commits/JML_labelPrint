# 标签打印系统自动更新部署手册

## 1. 准备工作（一次性）

### 1.1 服务端准备
*   **共享文件夹**: `\\172.16.1.8\10-公用文件夹\012 IT文件\LabelPrintUpdate`
*   **权限确认**: 确保所有运行该软件的电脑，对上述路径拥有**读取权限**。

### 1.2 客户端首次部署
请将以下文件打包发给客户，解压到其电脑上的任意目录（例如 `D:\LabelPrint`）：
1.  `Launcher.exe` (启动器主程序)
2.  `Launcher.dll`
3.  `Launcher.runtimeconfig.json`
4.  `appsettings.json` (配置文件)

**操作提示**: 
*   请客户以后双击 **`Launcher.exe`** 来启动程序。
*   建议为 `Launcher.exe` 创建桌面快捷方式，并重命名为“标签打印系统”。

---

## 2. 发布更新流程（每次更新时操作）

当您在 Visual Studio 中修改了代码并准备发布新版本时，请执行以下步骤：

### 2.1 修改版本号
1.  在 Visual Studio 解决方案资源管理器中，右键点击 `WinFormsApp1` 项目。
2.  选择 **属性 (Properties)**。
3.  进入 **打包 (Package)** 选项卡（或常规 -> 程序集信息）。
4.  将 **程序集版本 (Assembly version)** 和 **文件版本 (File version)** 增加（例如从 `1.0.0.0` -> `1.0.1.0`）。
    > **注意**: 如果不修改版本号，启动器将认为没有更新，不会下载新文件。

### 2.2 编译主程序
1.  在顶部工具栏将配置切换为 **Release**。
2.  右键点击 `WinFormsApp1` 项目，选择 **重新生成 (Rebuild)**。
3.  确保输出窗口显示“成功”。

### 2.3 上传更新包
1.  打开本地编译输出目录：
    `项目目录\WinFormsApp1\bin\Release\net8.0-windows`
2.  **全选**该目录下的所有文件（包括 `WinFormsApp1.exe`, `dll`, `json` 等）。
3.  **复制**到共享文件夹：
    `\\172.16.1.8\10-公用文件夹\012 IT文件\LabelPrintUpdate`
4.  如果提示文件冲突，选择**覆盖**所有文件。

---

## 3. 用户端效果

1.  用户双击桌面的 `Launcher.exe`。
2.  启动器自动对比本地与共享文件夹中的版本号。
3.  **发现新版本**:
    *   启动器界面提示“发现新版本，正在更新...”。
    *   自动从共享文件夹下载新文件并覆盖本地文件。
    *   更新完成后自动打开主程序。
4.  **无新版本**:
    *   直接快速启动主程序，用户几乎无感知。

---

## 4. 故障排查

*   **现象**: 修改了代码但客户没有更新。
    *   **检查**: 确认步骤 2.1 中是否修改了版本号？
*   **现象**: 启动器提示“启动失败”。
    *   **检查**: 共享文件夹路径是否正确？客户电脑是否能访问该共享路径？
