# 用户登录与权限管理功能实现计划

我将为您实现完整的登录功能，并包含“踢人”（强制下线）的机制。

## 1. 数据库脚本 (SQL)
我将为您提供以下 SQL 脚本（您可以直接在 SQL Server 中执行，或由我将其封装在程序中自动执行）：
*   创建 `SystemUsers` 表：包含 `ID`, `User`, `Password`, `Enable` 字段。
*   初始化数据：插入默认用户 `pp`，密码 `123`，启用状态 `1`。

## 2. 登录界面 (Form4)
*   **创建 Form4**:
    *   **UI**: 包含账号输入框 (`textBox1`)、密码输入框 (`textBox2`)、登录按钮 (`button1`)。
    *   **逻辑**:
        *   查询数据库验证账号密码。
        *   检查 `Enable` 字段：如果为 `0` (false)，提示“账号已禁用”并阻止登录。
        *   登录成功：保存当前用户信息，隐藏 `Form4`，打开 `Form1`。

## 3. 程序入口修改 (Program.cs)
*   修改 `Main` 方法，将启动窗体从 `Form1` 改为 `Form4`。

## 4. “踢人”机制 (运行时封禁)
为了实现“不让他们用了”（即管理员禁用账号后，正在使用的用户也会被踢出）：
*   **当前用户状态存储**: 定义一个全局静态变量 `CurrentUser` 记录当前登录账号。
*   **定时检查 (Form1)**:
    *   在 `Form1` 中添加一个 `Timer` (每 30 秒或 1 分钟触发一次)。
    *   **逻辑**: 定时查询数据库中当前用户的 `Enable` 状态。
    *   **效果**: 如果发现 `Enable` 变为 `0`（被管理员禁用了），弹出警告“您的账号已被禁用，系统即将退出”，然后强制关闭程序。

## 执行步骤
1.  创建 SQL 表脚本（将以注释形式提供或创建 `.sql` 文件）。
2.  创建 `Form4` 及其 UI/逻辑代码。
3.  修改 `Program.cs` 入口。
4.  在 `Form1` 中添加定时检测逻辑。
